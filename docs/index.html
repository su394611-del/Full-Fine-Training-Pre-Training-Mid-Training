DistilBERT Full Fine-Tuning and Model Evaluation

An educational Python and Hugging Face project demonstrating Transformer fine-tuning for customer-support message classification.

Project Features

  • DistilBERT pretrained Transformer model
  • Full model fine-tuning using PyTorch
  • Hugging Face Transformers Trainer API
  • Customer-support text classification
  • Billing, technical, account and feature request classes
  • Tokenization and dynamic batch padding
  • Stratified training and validation split
  • Frozen-backbone fine-tuning comparison
  • Accuracy and weighted F1 evaluation
  • Classification report and confusion matrix
  • Model checkpoint saving and inference
  • CPU and optional CUDA GPU execution
  • Python and Jupyter Notebook examples

Fine-Tuning Approaches

Full Fine-Tuning

Updates the pretrained DistilBERT encoder and classification head for a four-class customer-support classification task.

Frozen-Backbone Training

Freezes the DistilBERT encoder and trains the classification head as a baseline.

Dataset and Evaluation

The educational dataset contains 30 examples split into 24 training and 6 validation records. Results are not intended as production benchmarks.

Technologies

Python, PyTorch, Hugging Face Transformers, Datasets, Scikit-learn, DistilBERT, Jupyter Notebook and CUDA.

Project Scope

This project demonstrates fine-tuning of an existing pretrained encoder. It does not implement foundation-model pre-training or mid-training.
